# telly-bot

> This project was created using `bun init` in bun v1.1.8. [Bun](https://bun.sh) is a fast all-in-one JavaScript runtime.

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run server
```

To develop:

```bash
bun run dev
```

To lint files:

```bash
bun run eslint
```

To fix code syntax:

```bash
bun run prettier
```
